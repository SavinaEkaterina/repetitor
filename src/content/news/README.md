# ИНСТРУКЦИЯ ПО ПУБЛИКАЦИИ НОВОСТЕЙ И СТАТЕЙ

Инструкция для **Виктории Сергеевны Тетерядченко** по добавлению, редактированию и скрытию статей на сайте.

---

## 🚀 БЫСТРЫЙ СТАРТ: КАК ДОБАВИТЬ НОВУЮ СТАТЬЮ

1. Откройте папку **`src/content/news/`**.
2. Скопируйте файл **`_template.md`** и переименуйте его. Имя файла пишется латинскими буквами через дефис (например, `kak-vyuchit-glagoly.md`).
3. Заполните данные в верхней части файла (между линиями `---`).
4. Напишите текст статьи ниже второй линии `---`.
5. Установите `published: true` — статья автоматически появится на сайте!

---

## 📋 НАСТРОЙКА ПОЛЕЙ СТАТЬИ (ВЕРХНИЙ БЛОК)

```yaml
---
id: "blog-4"                           # Уникальный номер статьи (blog-4, blog-5 и т.д.)
slug: "kak-vyuchit-glagoly"            # Адрес страницы на сайте латиницей
title: "Как легко выучить 50 глаголов"  # Заголовок статьи
summary: "Простая методика запоминания" # Анонс для карточки
category: "Для родителей"               # Категория: "Для родителей", "ОГЭ", "Взрослым"
readTime: "5 мин"                      # Время чтения
date: "2026-09-25"                     # Дата публикации (ГГГГ-ММ-ДД)
published: true                        # true — опубликовать, false — скрыть (черновик)
isDemoPost: false                      # false для реальных статей
tags:                                  # Теги статьи
  - "Грамматика"
  - "Советы"
image: "/assets/news/glagoly.jpg"      # Картинка (опционально)
---
```

---

## 💡 ОФОРМЛЕНИЕ ТЕКСТА СТАТЬИ

После второй линии `---` пишется сам текст:

- **Абзацы**: просто отступайте пустой строкой между абзацами.
- **Подзаголовок**: пишется через `## Заголовок`.
- **Списки**: пишите пункты со знака минус `- Пункт` или цифры `1. Пункт`.

---

## 🔒 КАК СКРЫТЬ ИЛИ ОПУБЛИКОВАТЬ СТАТЬЮ

- **Скрыть статью (черновик)**: укажите `published: false`
- **Опубликовать статью**: укажите `published: true`

Скрытые статьи не отображаются посетителям сайта, но сохраняются в вашей папке.

---

## 🖼️ КАК ДОБАВИТЬ КАРТИНКУ К СТАТЬЕ

1. Положите файл изображения в папку **`public/assets/news/`** (например, `glagoly.jpg`).
2. В файле статьи укажите путь: `image: "/assets/news/glagoly.jpg"`.
