# ИНСТРУКЦИЯ ПО САМОСТОЯТЕЛЬНОМУ РЕДАКТИРОВАНИЮ САЙТА
## Руководство для Виктории Сергеевны Тетерядченко

Эта инструкция создана для того, чтобы вы могли легко и безопасно менять информацию на сайте — тексты, описания программ, цены, контакты, отзывы, частые вопросы, документы, фотографии, видео и статьи в блоге.

---

## 💡 Главный принцип работы с сайтом

> **«Чтобы изменить основную информацию сайта, вам не нужно искать текст внутри программных React/TSX-файлов. Весь основной редактируемый контент находится в папке `src/content/`.»**

---

## 🚀 Пошаговый порядок редактирования через GitHub

Чтобы внести правки без установки специальных программ на компьютер:

1. Откройте репозиторий проекта на сайте **GitHub**.
2. Перейдите в папку **`src/content/`**.
3. Найдите и откройте нужный **JSON-файл** (или папку `news/` для статей).
4. Нажмите на иконку карандаша *(Edit this file)* в правой верхней части.
5. Измените нужный текст внутри кавычек.
6. Сохраните изменения, нажав зеленую кнопку **«Commit changes»**.
7. После сохранения изменений обновление сайта зависит от настроек хостинга/деплоя проекта. Проверьте результат на опубликованном сайте.

## 🔒 Как временно скрыть направление или раздел сайта

Для каждого из основных направлений предусмотрен единый переключатель:

```json
"published": true
```
*(направление открыто и доступно)*

```json
"published": false
```
*(направление временно скрыто/приостановлено)*

### Где настраиваются основные направления:

1. **Подготовка к школе**, **Школьный английский**, **Подготовка к ОГЭ**, **Для взрослых**, **Авторские курсы**:
   Файл **`src/content/programs.json`** → найти нужную запись по `"id"` (`"school-preparation"`, `"school-english"`, `"oge"`, `"adults"`, `"courses"`) и изменить `"published": false`.
2. **Бесплатные материалы**:
   Файл **`src/content/free-courses.json`** → в самом начале файла изменить `"published": false`.

### Что происходит при `"published": false`:
- Направление автоматически **исчезает из меню шапки (Header)**.
- Автоматически **исчезает из бургер-меню (FullNavigator)**.
- Автоматически **исчезает из подвала сайта (Footer)**.
- **Скрывается с хаба детских программ (`/children`)** и списка направлений на Главной странице.
- Сам URL страницы (например, `/oge`) **сохраняется**, но при прямом переходе человек увидит сообщение:
  *«Набор на это направление временно приостановлен»* (или *«Раздел авторских курсов временно закрыт»*).

### Двухуровневая система скрытия для Авторских курсов и Бесплатных материалов:
- **Уровень 1 (весь раздел)**: `"published": false` в `programs.json` (для `courses`) или в `free-courses.json` скрывает весь раздел.
- **Уровень 2 (конкретный курс или памятка)**: внутри `courses.json` и `free-courses.json` у каждого отдельного курса/гайда есть собственный `"published": true/false`. Это позволяет убрать один спецкурс, не закрывая весь раздел.

| **`faq.json`** | Вопросы и ответы |

## 📞 Важное правило по контактам (`contacts.json`)

> **«Контактные данные редактируются только в `contacts.json`. Не нужно менять Telegram, VK, MAX и email в других файлах.»**

Файл **`src/content/contacts.json`** является единственным источником контактной информации для всего сайта:
- **Telegram URL**: `"telegramUrl"`
- **ВКонтакте URL**: `"vkUrl"`
- **MAX Messenger URL**: `"maxUrl"`
- **Email**: `"email"` (`contact@slavoladova.ru`)
- **График работы**: `"workingHours"`
- **Заметка о локации**: `"locationNote"`

## ⚠️ Внимание: синтаксис JSON

> **JSON чувствителен к синтаксису. Не удаляйте кавычки, фигурные `{}` / квадратные `[]` скобки и запятые. Если после изменения сайт перестал собираться, сначала проверьте последнюю правку в JSON.**

## 📰 Блог и публикации (`src/content/news/`)

Все статьи блога хранятся в папке **`src/content/news/`** в виде отдельных `.md` (Markdown) файлов:

1. Чтобы добавить новую статью, скопируйте файл **`_template.md`** и переименуйте его латинскими буквами.
2. Заполните параметры в начале файла и напишите текст.
3. При `published: true` статья автоматически появится на сайте!
